# Security policy

Dadblock reads page text, so I take security reports seriously.

**Please report vulnerabilities privately** to support@dadblock.org (subject: "Dadblock security").
Do not open a public issue for something that could be exploited. I will reply as soon as I can,
and I will credit you in the changelog if you want.

Useful to include: the extension version (`chrome://extensions`), the page or message that triggers it,
and what you expected to happen.

Out of scope: the cloud service's private deployment details (its source is not in this repository)
and reports that only say "AI can be wrong". That is documented and expected.
